# Құран курсы

A static, mobile-first website for learning (Әліппе, Тәжуид, Құран). No build step needed.

```bash
cd quran-course && python3 -m http.server 8000   # http://localhost:8000
```

## Structure
- `index.html`: top bar (settings in the top-left corner) and bottom navigation (Басты бет, Профиль)
- `css/styles.css`: palette `#FAF6EE #213E32 #567B62 #E9E0D1 #C9A66B`, animations, `prefers-reduced-motion`
- `js/data.js`: courses, lessons, exercises, achievements. **Videos go in each lesson's `video` field** (`{ youtube: "ID" }` or `{ src: "media/x.mp4" }`)
- `js/store.js`: progress, streak, achievements and settings, saved in `localStorage`
- `js/app.js`: hash router and pages (home, course, lesson, profile, settings)

## Course illustrations
| Slot | File | Shown at |
|---|---|---|
| Әліппе | `assets/illustrations/alippe-{320,640}.webp` (+ `.svg` master) | card 104–132px, header 184–224px |
| Тәжуид | `assets/illustrations/tajweed-{320,640}.webp` | same |
| Құран  | `assets/illustrations/quran-{320,640}.webp` | same |

The current assets are layered vector illustrations with a soft 3D look (gradients, shadows, warm light),
generated by `tools/build_illustrations.py`. The Quran pages carry no real text, only a non-readable texture.
To swap in rendered 3D images (Blender, Midjourney, etc.), replace those files with a **square, transparent-background**
image at the same names, in two sizes: 320×320 and 640×640 WebP. Nothing in the code needs to change.

Regenerate the assets:
```bash
python3 tools/build_illustrations.py && node tools/render_webp.mjs
```
