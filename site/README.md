# Фитнес-жабдық дүкенінің сайты

Статикалық бір беттік сайт (HTML/CSS/JS), орыс және қазақ тілдерінде.

## Файлдар
| Файл | Не үшін |
|---|---|
| `index.html` | Беттің құрылымы |
| `styles.css` | Дизайн (түстер `:root` ішінде, `--accent` — негізгі түс) |
| `config.js` | **Бренд атауы, телефон, WhatsApp, Instagram, мекенжай, тауарлар** |
| `i18n.js` | Барлық мәтіндер (RU / KZ) |
| `app.js` | Каталог, сүзгі, сұрыптау, модаль, форма |

## Деректерді өзгерту
1. `config.js` ашып, `brand`, `phone`, `whatsapp` (тек цифрлар, мысалы `77011234567`), `instagram`, `address` мәндерін ауыстырыңыз.
2. Тауар қосу үшін `PRODUCTS` тізіміне жаңа объект қосыңыз (`id` бірегей болсын, `cat` — `CATEGORIES` ішіндегі id).
3. Мәтіндерді `i18n.js` ішінде өзгертіңіз. Пікірлер — мысал, шынайыларымен ауыстырыңыз.

Өтінім формасы клиенттің мәліметтерімен WhatsApp-ты ашады (сервер қажет емес).

## Жергілікті іске қосу
```bash
cd site
python3 -m http.server 8000
# http://localhost:8000
```

## Жариялау
- **Netlify (ең оңайы)**: app.netlify.com/drop бетіне `site` папкасын сүйреп тастаңыз.
- **GitHub Pages**: Pages тек түбірден немесе `/docs` папкасынан жариялайды, сондықтан `site/` ішіндегі файлдарды бөлек репоның түбіріне салып, Settings → Pages → Branch: `main` / `root` таңдаңыз.
