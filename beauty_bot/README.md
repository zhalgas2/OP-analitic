# 🌸 Beauty Shop — Telegram бот

Beauty тауарларын сататын дүкенге арналған Telegram бот.

## Не істей алады

- 🛍 **Каталог**: санаттар → тауарлар → тауар карточкасы (сурет, сипаттама, баға)
- 🛒 **Себет**: санын қосу/азайту, тазалау, жалпы сома, тегін жеткізуге дейін қанша қалғаны
- ✅ **Тапсырыс**: аты → телефон (бір батырмамен) → жеткізу түрі → мекенжай → түсініктеме → растау
- 🔔 **Админге хабарлама**: жаңа тапсырыс бірден келеді, статусты батырмамен өзгертесіз
  (Қабылданды / Жолда / Жеткізілді / Бас тартылды) → клиентке автоматты хабар барады
- 📦 Клиент өз тапсырыстарын көре алады, 📞 Байланыс бөлімі бар
- Админ командалары: `/orders` (соңғы 10 тапсырыс), `/myid` (chat id-іңізді білу)

## Іске қосу

1. Telegram-да **@BotFather** → `/newbot` → токен аласыз.
2. Орнату:
   ```bash
   cd beauty_bot
   pip install -r requirements.txt
   ```
3. Алдымен админ id-іңізді біліңіз: ботты `ADMIN_IDS`-сіз іске қосып, ботқа `/myid` жазыңыз.
4. Іске қосу:
   ```bash
   BOT_TOKEN="123456:ABC..." ADMIN_IDS="123456789" python bot.py
   ```
   Бірнеше админ болса: `ADMIN_IDS="111,222"`.

### Айнымалылар

| Айнымалы | Не үшін |
|---|---|
| `BOT_TOKEN` | @BotFather берген токен (міндетті) |
| `ADMIN_IDS` | Тапсырыстар келетін адамдардың chat id (үтір арқылы) |
| `BOT_DB_PATH` | SQLite файлы (әдепкі: `beauty_bot/shop.db`) |
| `CATALOG_PATH` | Тауарлар файлы (әдепкі: `beauty_bot/products.json`) |

## Ботта админ ретінде

- 📸 **Тауарға фото қосу:** ботқа фотоны жай жіберіңіз → «Қай тауарға?» батырмасын таңдаңыз.
- 💬 **WhatsApp нөмірі:** `/whatsapp 77011234567`
- 📸 **Instagram:** `/instagram username` (немесе профиль сілтемесі)
- 📍 **Мекенжай:** `/address Алматы, Абай 10`
- 🕒 **Жұмыс уақыты:** `/hours Күн сайын 10:00–20:00`
- `/admin`: админ командаларының тізімі

Бұл баптаулар `shop.db` ішінде сақталады, бот қайта іске қосылғанда да жойылмайды.

## Тауарларды өзгерту

Барлығы `products.json` ішінде: дүкен аты, байланыс, жеткізу бағасы, санаттар, тауарлар.
Тауарға сурет қосу үшін `photo` өрісіне суреттің сілтемесін (https://...) жазыңыз.
Өзгерткеннен кейін ботты қайта іске қосыңыз.

> ⚠️ Токенді кодқа немесе GitHub-қа жазбаңыз — тек айнымалы (environment variable) арқылы беріңіз.
> Хостингте `shop.db` сақталуы үшін тұрақты диск керек.

## Mac-та фонда тұрақты жұмыс істету (Terminal-сыз)

```bash
cd ~/OP-analitic && git pull && bash beauty_bot/install_mac.sh "BOT_TOKEN" "ADMIN_ID"
```

Бот Mac қосылғанда өзі іске қосылады, құласа қайта қосылады. Terminal-ды жаба беруге болады.

- Күйін тексеру: `bash ~/OP-analitic/beauty_bot/install_mac.sh status`
- Тоқтату: `bash ~/OP-analitic/beauty_bot/install_mac.sh stop`
- Жаңарту: `git pull`, содан кейін орнату командасын қайта іске қосыңыз.

Mac ұйықтап қалса (қақпағы жабық), бот уақытша жауап бермейді.
